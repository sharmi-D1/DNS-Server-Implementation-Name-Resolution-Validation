📌 Overview

This project focused on implementing and configuring a DNS Server using Windows Server 2022 to understand how domain name resolution works in real-world network environments.

The project involved creating DNS zones, configuring DNS records, validating name resolution across systems, and troubleshooting DNS-related issues. To ensure cross-platform reliability, DNS functionality was tested using a Kali Linux client through DNS query validation and response analysis.

This hands-on experience provided practical exposure to DNS administration, network troubleshooting, and foundational networking concepts used in enterprise environments.
